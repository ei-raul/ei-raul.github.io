Como um programa executa

O Python executa as linhas de cima para baixo, uma de cada vez. Cada linha trabalha com os valores que existem naquele momento.

Pergunta para a turma antes de avançar até o fim: depois que x passa a valer 10, o valor de y muda? Por quê?

Este quadro é um teste de mesa: cada clique executa uma linha e a tabela registra o valor das variáveis depois dela. Usaremos o mesmo recurso nas decisões e nas repetições.

Variáveis

Uma variável é um nome associado a um valor guardado na memória. Usamos o nome para recuperar o valor depois.

nome→"Ana" idade→19 altura→1.68

O sinal = é a atribuição: o Python calcula o lado direito e guarda o resultado no nome à esquerda. Não é a igualdade da matemática.

x = 3 → x passa a valer 3x = x + 1 → x passa a valer 4

Entrada, processamento e saída

A maioria dos programas simples segue três etapas:

  1. Entrada: ler os dados necessários.
  2. Processamento: fazer os cálculos.
  3. Saída: mostrar o resultado.

Antes de programar, identifique cada etapa no enunciado. Ex.: “Leia três notas e mostre a média” → entrada: 3 notas; processamento: somar e dividir por 3; saída: a média.

Teste sem os parênteses: n1 + n2 + n3 / 3. O resultado muda por causa da ordem das operações.

if: executar só quando a condição é verdadeira

A estrutura tem três partes: a palavra if, uma condição e dois-pontos. As linhas que pertencem ao if ficam recuadas com 4 espaços.

Se a condição for True, o bloco recuado executa. Se for False, o Python pula o bloco e segue para a próxima linha sem recuo.

Execute com 17 e depois troque a entrada para 20. Compare as saídas.

Sem o recuo, o Python não sabe quais linhas pertencem ao if:

if e else: dois caminhos

else define o que fazer quando a condição é falsa. Exatamente um dos dois blocos executa, nunca os dois.

else não tem condição: ele cobre todos os casos que o if não cobriu.

Um número é par quando o resto da divisão por 2 é zero.

8 % 2 → 07 % 2 → 1

if, elif e else: vários caminhos

As condições são testadas de cima para baixo. A primeira verdadeira executa e as demais são ignoradas. Acompanhe no teste de mesa quais linhas são puladas.

A ordem importa. Por que a nota 9.5 recebe conceito C aqui?

Decisões aninhadas

Um if pode ficar dentro de outro. O bloco interno só é avaliado quando a condição externa é verdadeira. O recuo mostra quem está dentro de quem.

Use aninhamento quando a segunda pergunta só faz sentido depois da primeira. Na calculadora ao lado, só vale a pena olhar o divisor quando a operação é uma divisão.

Cada else pertence ao if que está no mesmo recuo. Troque tem_titulo para True no teste de mesa mentalmente: qual linha muda?

Muitas vezes um aninhamento pode virar and: if idade >= 16 and tem_titulo:. Escolha a forma mais fácil de ler.

Operadores lógicos: and, or, not

ABA and BA or B

and: as duas precisam ser verdadeiras. or: basta uma. not inverte: not True → False.

Armadilhas nas condições

  1. Intervalos. O Python aceita comparações encadeadas, como na matemática: 18 <= idade < 60 equivale a idade >= 18 and idade < 60.
  2. O or incompleto. cor == "azul" or "verde" está sempre certo, porque um texto não vazio sozinho já vale True. Escreva a comparação completa dos dois lados: cor == "azul" or cor == "verde".
  3. Igualdade com float. Números decimais são guardados de forma aproximada: 0.1 + 0.2 não é exatamente 0.3. Arredonde antes de comparar.
  4. Texto não é número. "10" > "9" é False, porque textos são comparados letra a letra. Converta com int() antes.

while: repetir enquanto a condição for verdadeira

O bloco recuado executa, a condição é testada de novo, e assim por diante. Quando a condição fica falsa, o programa segue para depois do laço.

Todo while com contador tem três partes:

  1. inicialização antes do laço: i = 1
  2. condição testada a cada volta: i <= 4
  3. atualização dentro do laço: i = i + 1

while com valor de parada

Quando não sabemos quantas vezes vamos repetir, combinamos um valor de parada com o usuário. Aqui, digitar -1 encerra a leitura.

Repare que a primeira leitura acontece antes do laço e a próxima leitura é a última linha dentro dele.

Mude as entradas e execute de novo. Teste também começando com -1.

Cuidado: laço infinito

Se a condição nunca ficar falsa, o laço nunca termina. No código abaixo falta a atualização: i vale 1 para sempre.

nao_execute.pyexemplo sem botão de executar
i = 1
while i <= 5:
    print(i)
# falta i = i + 1: a condição é sempre True
Não execute laços infinitos nesta página: o navegador trava. No terminal ou no IDLE, Ctrl+C interrompe o programa.

Validando entradas e menus

O usuário nem sempre digita o que esperamos. O while permite repetir a pergunta enquanto a resposta for inválida:

  1. leia o valor;
  2. enquanto for inválido: avise e leia de novo;
  3. depois do laço, o valor com certeza é válido.

O mesmo raciocínio cria menus: o programa repete as opções até o usuário escolher sair. Você vai usar esse padrão na agenda telefônica da próxima aula.

Laços aninhados

Um laço pode ficar dentro de outro. Para cada volta do laço de fora, o laço de dentro executa todas as suas voltas. Aqui são 2 × 3 = 6 impressões.

Laços aninhados aparecem sempre que há linhas e colunas: tabelas, desenhos, tabuleiros e, na próxima aula, matrizes.

No desenho ao lado, a linha 1 tem 1 asterisco, a linha 2 tem 2… O laço de dentro usa a variável do laço de fora.

"*" * 3 → '***'
