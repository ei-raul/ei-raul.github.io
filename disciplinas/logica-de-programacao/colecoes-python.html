Strings: texto é uma sequência

Você já usa strings desde a primeira aula. A novidade de hoje: uma string é uma sequência de caracteres, em ordem, e podemos acessar cada um deles.

Podemos criar strings com aspas simples, duplas ou triplas (para várias linhas). O resultado é o mesmo tipo: str.

A função len() devolve o tamanho de uma sequência, ou seja, quantos elementos ela tem. Espaços também contam.

len("casa") → 4len("a b") → 3len("") → 0

Índices: a posição de cada caractere

Cada caractere ocupa uma posição numerada. A contagem começa em 0. Também dá para contar de trás para frente com índices negativos: -1 é o último.

Para acessar um caractere: texto[posição].

Se a string tem tamanho n, os índices válidos vão de 0 até n - 1 (ou de -n até -1).

A última linha do exemplo pede o índice 6 de uma string com 6 caracteres. Peça para a turma prever o que vai acontecer antes de executar.

Fatiamento: pedaços de uma sequência

texto[início:fim:passo] devolve um pedaço. O início entra, o fim fica de fora. Qualquer parte pode ser omitida.

OmitidoValor assumido
iníciocomeço da sequência
fimaté o final
passo1 (de um em um)

Passo negativo percorre de trás para frente. Por isso s[::-1] inverte a string.

Construindo strings: o padrão acumulador

letra + invertida coloca a letra nova na frente; invertida + letra colocaria atrás e copiaria a palavra igual.

split e join: da string para a lista e de volta

split() quebra uma string em pedaços e devolve uma lista. Sem argumento, separa pelos espaços.

join() faz o caminho inverso: junta os itens de uma lista usando a string como separador.

"a,b,c".split(",") → ['a', 'b', 'c']"-".join(['a', 'b']) → 'a-b'int("10") → 10
Este é o jeito mais comum de ler vários valores digitados na mesma linha. Os pedaços continuam sendo texto: converta com int() ou float() antes de fazer contas.

Strings são imutáveis

Não é possível alterar um caractere de uma string existente. Para “modificar” um texto, criamos uma string nova a partir da antiga.

Listas

Uma lista guarda vários valores em ordem, entre colchetes [ ] e separados por vírgula. Os valores podem ser de qualquer tipo, inclusive misturados.

Tudo o que vimos em strings vale aqui: índices, índices negativos, fatiamento, len(), in e percurso com for.

Listas são mutáveis

Diferente das strings, uma lista pode ser alterada depois de criada: trocar, incluir e remover elementos.

Busca em listas

Buscar é percorrer a lista comparando cada elemento com o que procuramos. Quando achar, guardamos a posição e paramos com break. Se nunca achar, a posição continua -1.

Uma variação importante: em vez de procurar um valor conhecido, procurar a posição do maior. Guardamos o índice do melhor até agora e trocamos quando aparece alguém maior.

Com duas listas paralelas (mesma posição = mesmo registro), a posição encontrada em uma serve para consultar a outra.

Esse raciocínio é a base da aula de Ordenação e Busca. in, index() e max() fazem exatamente isso por dentro.

Construindo listas com laços

Padrão muito comum: começar com uma lista vazia e ir acrescentando com append() dentro de um laço.

O operador % devolve o resto da divisão. Um número é par quando o resto da divisão por 2 é zero.

7 % 2 → 18 % 2 → 0list(range(1, 6)) → [1, 2, 3, 4, 5]

No segundo exemplo, os valores digitados podem ser escritos no campo Entrada, um por linha, antes de executar. Se o campo estiver vazio, o navegador abre uma caixa para digitar.

Extra: a forma compacta (compreensão de lista)

Cuidado: dois nomes, uma lista

b = a não copia a lista. As duas variáveis passam a apontar para a mesma lista na memória; alterar por um nome altera o que o outro enxerga.

Para obter uma lista independente, use a.copy() (ou a[:]).

Com strings esse problema não aparece: como elas são imutáveis, nenhuma operação altera o texto compartilhado.

Matrizes: listas de listas

Uma matriz é uma lista em que cada elemento é outra lista: uma linha. Para chegar a um valor usamos dois índices: m[linha][coluna].

m[1] é a segunda linha inteira (uma lista). m[1][2] é o terceiro valor dessa linha.

len(m) é o número de linhas; len(m[0]), o número de colunas.

Matrizes aparecem em tabuleiros (jogo da velha, xadrez), planilhas, notas de alunos por avaliação, assentos de um cinema e imagens (cada pixel é uma posição).

Criando matrizes (e uma armadilha)

Para criar uma matriz de tamanho conhecido, montamos uma lista nova para cada linha dentro de um laço.

Atalho perigoso: [[0] * 4] * 3 não cria três linhas, e sim três nomes para a mesma linha, como no slide “Cuidado: dois nomes, uma lista”. Alterar uma altera todas.

Para ler uma matriz do teclado, cada linha pode ser digitada de uma vez, com os valores separados por espaço, e quebrada com split().

Tuplas

Uma tupla é uma sequência como a lista, escrita entre parênteses ( ). A diferença: é imutável. Depois de criada, não ganha, não perde e não troca elementos.

Use tuplas para dados que andam juntos e não devem mudar: coordenadas, data (dia, mês, ano), dias da semana.

Tupla com um único elemento precisa de vírgula: (42,). Sem a vírgula, (42) é apenas o número 42 entre parênteses.

Desempacotamento

Podemos distribuir os elementos de uma tupla em várias variáveis de uma só vez. A quantidade de variáveis precisa ser igual à quantidade de elementos.

Isso permite trocar o valor de duas variáveis sem usar uma variável auxiliar e percorrer listas de pares de forma legível.

enumerate() entrega pares (posição, elemento) durante o for.

list(enumerate(["a", "b"])) → [(0, 'a'), (1, 'b')]

zip e tuplas como registros

zip(a, b) percorre duas sequências lado a lado, entregando a cada volta uma tupla com um elemento de cada. É o jeito mais limpo de trabalhar com listas paralelas.

list(zip(["a", "b"], [1, 2])) → [('a', 1), ('b', 2)]

Se as listas tiverem tamanhos diferentes, zip para na menor.

Tuplas também funcionam como pequenos registros de tamanho fixo, em que cada posição tem um significado: (dia, mês, ano), (nome, nota), (x, y).

(1, 2, 2, 3).count(2) → 2("a", "b").index("b") → 1

Dicionários

Em listas e tuplas acessamos os valores pela posição. Em um dicionário, cada valor tem um nome: a chave. Escrevemos pares chave: valor entre chaves { }.

"nome"→"Ana" "matricula"→2026001 "curso"→"Sistemas de Informação"

As chaves não se repetem e normalmente são strings ou números. Os valores podem ser qualquer coisa, inclusive listas.

Acessar uma chave que não existe com colchetes gera erro. get() devolve None (ou um valor padrão) em vez de erro.

Percorrendo dicionários

Na f-string, :.2f mostra o número com duas casas decimais.

f"{4.5:.2f}" → '4.50'

Dicionário como contador

Problema clássico: quantas vezes cada palavra aparece em um texto? A chave é a palavra; o valor é a contagem.

A cada palavra: se ela já está no dicionário, somamos 1; se não está, ela entra com valor 1.

A versão curta usa get(chave, 0): devolve o valor atual, ou 0 se a chave ainda não existir.

{"a": 2}.get("a", 0) → 2{"a": 2}.get("b", 0) → 0

Agrupando e consultando com dicionários

Agrupar: o valor de cada chave pode ser uma lista. A cada item, se a chave ainda não existe, criamos a lista vazia; depois, acrescentamos o item na lista daquela chave.

Consultar: um dicionário também substitui longas cadeias de if/elif que só traduzem um valor em outro.

sorted(d) devolve as chaves em ordem, útil para exibir o resultado organizado.

sorted({"b": 1, "a": 2}) → ['a', 'b']

Estruturas combinadas

As estruturas podem ser combinadas. Uma lista de dicionários representa bem uma tabela: cada dicionário é uma linha (um aluno) e cada chave é uma coluna.

Para chegar a um valor interno, encadeamos os acessos da esquerda para a direita:

turma[2]["notas"][0]
terceiro aluno → suas notas → primeira nota.
